# Contributor avatars

Circular avatars used in the [main README](../../../README.md). Each image is a 160 × 160 transparent PNG displayed at 80 × 80 pixels, with a two-pixel light gray border in the source image.

The images are cropped and resized copies of the contributors' public GitHub avatars. The names, order, and profile links are maintained in [CONTRIBUTORS.md](../../../CONTRIBUTORS.md).
