# Shared legal workspaces

Give each legal project a shared home for its working documents and supporting material. Prism workspaces bring files, participants, and access roles together so the team can work from an organized collection.

## What you can do

- **Organize the work.** Create a named workspace with a description, and separate Primary Documents from Supporting Documents.
- **Bring in existing material.** Upload files from your device or browse your document library to reuse documents in a workspace.
- **Find files within a collection.** Search by file name or type, filter the list, and sort by name or date.
- **Invite the right participants.** Invite colleagues with Admin, Editor, or Viewer access. Recipients can accept or decline workspace invitations.
- **Keep access role-based.** Viewers can read workspace material; editors can contribute changes. Owners and admins manage access, while workspace deletion is reserved for the owner.

Use a workspace to keep a contract and its reference material together. The same collection can provide context for [Luna's document assistance](../ai-drafting/README.md) or become the starting point for a [multi-document tabular review](../tabular-review/README.md).

## Example: organize a supplier agreement

1. Open **Projects** and create a workspace with a name and short description, such as “Supplier agreement review.”
2. Invite the colleague preparing the draft as an Editor, and add participants who only need to read the material as Viewers.
3. In **Primary Documents**, add the agreement being reviewed. Choose **Upload** for a local file or **Browse Files** for an existing library document.
4. Add the proposal and earlier agreement under **Supporting Documents**.
5. Use the file list to locate the material needed for drafting or review, then continue with the relevant document workflow.

The interface uses Projects as the navigation label for these shared workspaces.

## Requirements and limits

Participants need to sign in and have access to the workspace. Copying a workspace link does not grant access or make its documents public.

Uploads require configured document storage. Invitation email delivery requires a configured mail provider and a running worker; creating a workspace alone does not confirm that invitation emails were delivered. See [deployment and mail setup](../../docs/deployment.md).

Workspaces organize documents and team access. They do not provide court scheduling, docket management, or real-time co-editing. Document comments and approval decisions are covered in [collaborative review and approvals](../review-and-approvals/README.md).
